For teachers
  • To use on another computer, copy the whole folder (for example with a flash drive) and open the START HERE file. The activities need no installation, internet or accounts. Keep every file in the same folder: the cards and every tool’s “Lab home” button find each other by filename.
  • Progress is saved only in this web browser on this computer. Nothing is sent anywhere and no names are collected.
  • Each activity also has its own reset option. Use the button below to clear everything before a new class.
  • New computer? Open CHECK_SAVING_WORKS.html once to make sure this browser keeps saved work.
  • Pixel Studio, Computer Builder and Rover are shared by Grades 6–11: tell each class which one to open.
  • Professional Profile Lab keeps one profile per computer: press Reset profile in the tool before the next student uses the computer.
