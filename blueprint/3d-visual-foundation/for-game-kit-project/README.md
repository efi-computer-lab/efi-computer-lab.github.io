# Files for the Game Kit project folder

Copy **both** of these into the top of the folder where your games are made (the Game Kit project):

- `CLAUDE.md`: standing instructions. Claude reads them at the start of every session: work without asking, publish and merge, add version numbers so no Ctrl+F5 is needed, keep the 3D style, lab PC rules.
- `.claude/settings.json`: actions Claude may do without asking you (git, building, testing, opening and merging the pull request).

On Windows, the `.claude` folder starts with a dot. If File Explorer hides it, turn on **View → Show → Hidden items**.
