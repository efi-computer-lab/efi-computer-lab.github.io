THE BRIEF

How Rover works

This is real Python. Same words, same brackets, same indentation as the programs you write in class — it just drives a rover instead of printing text.

  1. Pick a level. Read the brief on the right.
  2. Write your program in the box. Click a command underneath it to drop it in.
  3. Press RUN and watch. The rover does exactly what you wrote, in order, from the top.
  4. Crash into a wall? That is not a punishment — it tells you which line was wrong.
  5. Every level has a target number of lines. Beating it usually means using a loop instead of copying and pasting.
  6. Landing a level unlocks the next one. Every level is built on the one before it.
  7. The rover can be asked five questions: wall_ahead(), wall_left(), wall_right(), on_rock() and at_goal(). Later levels are unsolvable without them.
  8. def gives a name to a group of lines, and elif chains a second question onto an if. Both are ordinary Python and both turn up near the end.
Indentation is not decoration. Lines inside a for or an if must be pushed in with four spaces. Get that wrong and Python stops — exactly as it does in your real programs.
